Noise-Aware Bird Segregation Pipeline V3
==========================================

A Data-Centric Approach for False-Positive Suppression
in Passive Acoustic Monitoring

Version: 3.0.0
Author: Samarth Kolur


1. PROBLEM STATEMENT
--------------------

Pre-trained bioacoustic classifiers like BirdNET often produce false
positives when deployed in uncontrolled environments. Sounds such as
traffic, rain, wind, insects, and urban noise can be misclassified as
bird vocalizations. This "forced prediction" problem contaminates
training datasets and undermines downstream species identification.

The core challenge:
    BirdNET analyses every audio segment and always produces a prediction
    — even for non-bird sounds. There is no built-in "noise" class.


2. SOLUTION: DATA-CENTRIC PIPELINE
-----------------------------------

Instead of building a better model, we build a better dataset.

This pipeline treats data quality as the primary lever for improving
classification performance. The approach is based on:

  a) Hard-Negative Mining — Identify noise segments that BirdNET
     confidently misclassifies as birds, and explicitly include them
     in the negative class.

  b) Multi-Signal Verification — Use spectral heuristics, temporal
     consistency, and out-of-distribution detection to catch errors
     that any single method would miss.

  c) Active Learning — Use uncertainty sampling to find the most
     ambiguous segments and get expert labels for maximum information
     gain per annotation.

  d) Lightweight Classification — A Random Forest on BirdNET embeddings
     can be trained in under a minute, enabling rapid iteration.


3. PIPELINE ARCHITECTURE (8 Stages)
-------------------------------------

  Stage 1: Audio Segmentation & Standardization
    Input:  Raw recordings (data/iBC53/<species>/<file>.wav)
    Output: 3-second segments at 48 kHz (data/segmented/)
    File:   pipeline/stage1_segmentation.py

  Stage 2: BirdNET Embedding Extraction
    Input:  Segmented audio files
    Output: 1024-d BirdNET embeddings + confidence scores
    File:   pipeline/stage2_embeddings.py
    Note:   BirdNET-only (YAMNet and OpenL3 removed for simplicity)

  Stage 3: Hard-Negative Dataset Curation
    Input:  Embeddings + BirdNET confidences
    Output: Pseudo-labeled binary dataset (bird/noise) + train/val split
    File:   pipeline/stage3_hard_negative_dataset.py
    Key:    Uses spectral flatness to override BirdNET false positives

  Stage 4: Binary Classifier Training
    Input:  Curated train/val split from Stage 3
    Output: Trained Random Forest (or MLP) model
    File:   pipeline/stage4_binary_classifier.py
    Note:   RF is primary (<1 min training), MLP is optional secondary

  Stage 5: OOD Detection
    Input:  Bird-class embeddings
    Output: Trained Mahalanobis + Isolation Forest ensemble
    File:   pipeline/stage5_ood_filter.py
    Note:   AND-gate logic — both detectors must agree for bird label

  Stage 6: Active Learning (Optional, Interactive)
    Input:  Classifier + unlabeled pool
    Output: CSV of uncertain samples for expert review
    File:   pipeline/stage6_active_learning.py
    Note:   Requires human input. Use --skip-active-learning for unattended runs.

  Stage 7: Post-Processing & Ecological Validation
    Input:  Classifier predictions + audio files
    Output: Refined predictions (temporal smoothing + spectral check)
    File:   pipeline/stage7_postprocessing.py

  Stage 8: Ensemble Decision & Final Output
    Input:  All pipeline signals (classifier, OOD, post-processing, BirdNET)
    Output: Final bird/noise labels → clean dataset
    File:   pipeline/stage8_ensemble.py
    Method: Weighted confidence voting (not simple threshold counting)

5. USAGE
--------

  Full pipeline:
    python run_pipeline.py --stage all

  Individual stages:
    python run_pipeline.py --stage segment
    python run_pipeline.py --stage embed
    python run_pipeline.py --stage curate
    python run_pipeline.py --stage train
    python run_pipeline.py --stage ood
    python run_pipeline.py --stage active
    python run_pipeline.py --stage postprocess
    python run_pipeline.py --stage ensemble
    python run_pipeline.py --stage evaluate

  Unattended (skip active learning):
    python run_pipeline.py --stage all --skip-active-learning

  Limited files (testing):
    python run_pipeline.py --stage embed --max-files 20

  Ablation study:
    python run_pipeline.py --stage ablation

7. ACADEMIC FRAMING
-------------------

This work contributes a Methodological Framework — a "Context-Aware
Infrastructure for False-Positive Suppression" — rather than a novel model.

The contribution is:
  - A reproducible, data-centric pipeline that can be applied to any
    pre-trained bioacoustic classifier (not just BirdNET)
  - Hard-negative mining + active learning for efficient human-in-the-loop
    dataset curation
  - Multi-signal ensemble verification using spectral, statistical, and
    machine learning methods
  - Empirical validation on the IBC53 dataset of Indian bird recordings


8. GLOSSARY
-----------

  Hard Negative:     Noise segment that a model confidently misclassifies
                     as a bird call. Adding these to training data improves
                     robustness.

  Active Learning:   Iterative process where the model identifies its most
                     uncertain predictions, and a human expert provides
                     labels for maximum information gain.

  OOD Detection:     Out-of-Distribution detection — identifying samples
                     that differ significantly from the training data.

  Pseudo-Label:      Approximate label assigned automatically (e.g., via
                     BirdNET confidence) rather than by a human annotator.

  Ensemble:          Combining multiple independent signals to make a more
                     robust decision than any single signal alone.

  HPSS:              Harmonic-Percussive Source Separation — a signal
                     processing technique that separates harmonic (tonal)
                     and percussive (transient) components of audio.

  Spectral Flatness: Measure of how noise-like a signal is. High flatness
                     (~1.0) = broadband noise; low flatness (~0.0) = tonal.
